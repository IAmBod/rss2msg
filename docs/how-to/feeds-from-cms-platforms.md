# Feeds from CMS Platforms

Most content management and publishing platforms expose an RSS or Atom feed at a
predictable, platform-specific URL. rss2msg polls any such URL — to the service it
is just another feed. There is **nothing CMS-specific to configure**: once you know
the feed URL, you add it like any other feed (see [Configure Feeds](configure-feeds.md)):

```yaml
feeds:
  - url: https://example.com/feed/   # the platform's feed URL (see table below)
    interval: 15m
    sinks: [default]
```

This page lists where each platform publishes its feed so you don't have to
reverse-engineer it. Replace the example hosts with your own.

## Finding any feed URL

Before reaching for the table, two shortcuts work on most sites:

- **Autodiscovery link.** Standards-compliant pages advertise their feed in the
  HTML `<head>`. View source and look for:
  `<link rel="alternate" type="application/rss+xml" href="…">` (or
  `type="application/atom+xml"`). The `href` is the feed URL.
- **Try the common path.** Many engines respond at `/feed/`, `/feed`, `/rss`,
  `/rss.xml`, `/atom.xml`, or `/index.xml`. Open the candidate in a browser — a
  feed renders as XML (or as the browser's feed view) rather than a normal page.

Once you have a working URL, paste it into a `feeds[].url` entry.

## Platform reference

| Platform | Feed URL | Notes |
| --- | --- | --- |
| **WordPress** | `https://site/feed/` | Also `https://site/feed/atom/` for Atom. Scoped feeds exist for categories (`/category/<slug>/feed/`), tags (`/tag/<slug>/feed/`), authors (`/author/<name>/feed/`), and comments (`/comments/feed/`). |
| **Ghost** | `https://site/rss/` | A tag or author archive has its own feed at `…/tag/<slug>/rss/` and `…/author/<slug>/rss/`. |
| **Drupal** | `https://site/rss.xml` | The default feed; site-specific feeds are generated by Views and may live at other paths. Use autodiscovery if `/rss.xml` is absent. |
| **Joomla** | `https://site/index.php?format=feed&type=rss` | Menu items and categories can expose their own feed links; check the page's autodiscovery `<link>`. |
| **Squarespace** | `https://site/<collection>?format=rss` | Append `?format=rss` to a blog (collection) URL. |
| **Wix** | `https://site/blog-feed.xml` | Available when the site uses the Wix Blog app. |
| **Blogger / Blogspot** | `https://site/feeds/posts/default` | Atom by default; add `?alt=rss` for RSS. Comments: `/feeds/comments/default`. |
| **Medium** | `https://medium.com/feed/@<user>` | Publications: `https://medium.com/feed/<publication>`. Custom-domain publications: `https://<domain>/feed`. |
| **Tumblr** | `https://<blog>.tumblr.com/rss` | Append `/rss` to the blog URL. |
| **Substack** | `https://<name>.substack.com/feed` | Works for custom domains too: `https://<domain>/feed`. |
| **Hugo** | `https://site/index.xml` | The default RSS output; section feeds at `…/<section>/index.xml`. |
| **Jekyll** | `https://site/feed.xml` | Produced by the `jekyll-feed` plugin (Atom). |
| **Discourse** | `https://forum/latest.rss` | Most listings support `.rss`: categories (`/c/<slug>.rss`), tags (`/tag/<slug>.rss`), and topics (`/t/<slug>/<id>.rss`). |
| **Reddit** | `https://www.reddit.com/r/<sub>/.rss` | Also works for users (`/user/<name>/.rss`) and search results. Reddit rate-limits aggressive polling — keep `interval` generous. |
| **MediaWiki** | `https://wiki/w/index.php?action=feed&feed=rss` | Recent changes; many wikis also expose `Special:RecentChanges?feed=rss`. |
| **YouTube** | `https://www.youtube.com/feeds/videos.xml?channel_id=<ID>` | Per-channel uploads feed. Use `?playlist_id=<ID>` for a playlist. |

Feed paths are set by each platform and can change between major versions or be
disabled by site owners. If a documented URL 404s, fall back to the autodiscovery
`<link>` in the page source.

## Example: watch a blog and a forum

```yaml
feeds:
  - url: https://blog.example.com/feed/            # WordPress
    interval: 10m
    sinks: [default]
  - url: https://news.example.org/category/releases/feed/   # WordPress category
    interval: 5m
    sinks: [default]
  - url: https://forum.example.net/c/announcements.rss      # Discourse category
    interval: 15m
    sinks: [default]
```

rss2msg parses RSS, Atom, and JSON Feed identically (via `gofeed`), so feeds from
different platforms can be mixed freely in one config. Per-feed `http.headers` are
available if a platform's feed needs authentication — see
[Configure Feeds](configure-feeds.md).
