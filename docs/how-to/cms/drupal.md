# Drupal feeds

Drupal publishes a feed at a predictable URL. rss2msg polls it like any other feed —
there is nothing platform-specific to configure once you have the URL.

## Feed URL

| Feed | URL |
| --- | --- |
| Default | `https://site/rss.xml` |

Site-specific feeds are generated by Views and may live at other paths. If
`/rss.xml` is absent, use autodiscovery to find the feed.

## Add it to rss2msg

```yaml
feeds:
  - url: https://site.example.com/rss.xml
    interval: 15m
    sinks: [default]
```

If a documented path 404s, fall back to the page's autodiscovery `<link>` — see
[Finding any feed URL](../feeds-from-cms-platforms.md#finding-any-feed-url).
